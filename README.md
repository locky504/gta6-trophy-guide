Leonida Trophy Guide — an offline guide and tracker for all 55 PlayStation 5 trophies of Grand Theft Auto VI: every trophy with its official name, description and grade, a guide in our own words that cites its sources, a five-stage roadmap to the platinum, a flag on the one possibly-missable trophy, and a checklist whose progress is saved in the browser with export and import, kind and grade filters, search, and a spoiler setting that hides hidden trophies until they are earned. Static files only; it works with the network off.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — or serve `app/` with any static file server. To build the hand-in dossier locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
